本項目不是雞精筆記, 不是臨考試前臨急抱佛腳用
只是用來詳細地解說各種topic同concept
中學phy, chem, bio 三科相輔相成, 是未來在相關專業發展的必要基礎
以前舊制會考 絕大部分修讀理科的人都會phy, chem, bio 三科同時修讀
這notes系統原意希望同學能方便地在同時在phy chem bio 三科找到相關的條目
就算本身沒有修讀也可作參考

使用方法
先按左上角的accept license
此button一開始是(1,1,1) 分別代表已經載入的phy, chem, bio的筆記條目數量
按下accept license後才會載入筆記
之後會出現ALL, 就是所有條目
可以在最上方輸入要查的keyword 每次只可查找1個keyword 不要有空格space
然後會在左邊出現keyword的結果

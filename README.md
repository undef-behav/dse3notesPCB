本項目不是雞精筆記, 不是臨考試前臨急抱佛腳用，
只是用來詳細地解說各種topic同concept。
中學phy, chem, bio 三科相輔相成, 是未來在相關專業發展的必要基礎。
以前舊制會考 絕大部分修讀理科的人中4,5 都會phy, chem, bio 三科同時修讀，
去到預科AL才會只修讀某科。
這notes系統原意希望同學能方便地在同時在phy chem bio 三科找到相關的條目，
就算本身沒有修讀也可作參考。

使用方法:

ALL是所有條目的標題列表。
可以在最上方輸入要查的keyword單字 每次只可查找1個keyword 不要有空格space，
search後會在ALL旁邊出現剛才輸入的keyword
下面有3個column分別是phy, chem, bio 條目標題，
按下ALL旁邊出現的keyword會在這3個條目標題列表顯示該keyword的搜尋結果
輕按一下這個列表的標題會在左下的地方顯示此條目及上下一個條目的內容，
按下 左>>右 可以將顯示在左下的條目內容顯示在右下
